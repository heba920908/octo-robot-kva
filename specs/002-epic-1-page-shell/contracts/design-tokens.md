# Contract: Design Token Export (US1 / BMAD 1.1)

Governs `scripts/design-tokens.mjs`, its typed surface `scripts/design-tokens.d.mts`, and
the two generated files. Naming and value rules are in [research.md](../research.md) R3–R5
and [data-model.md](../data-model.md).

## CLI

| Command                                                           | Behaviour                                                                                          | Exit code                                              |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| `npm run tokens:build` (`node scripts/design-tokens.mjs`)         | Regenerates `src/styles/_tokens.scss` and `src/app/core/schemas/design-tokens.json` from DESIGN.md | 0 on success; 1 on an invalid source, naming the token |
| `npm run tokens:check` (`node scripts/design-tokens.mjs --check`) | Writes nothing; prints each drifting token or file                                                 | 0 when no drift; 1 on drift or an invalid source       |

## Module surface (`scripts/design-tokens.d.mts`)

```ts
export interface TokenFiles {
  readonly scss: string;
  readonly json: string;
}

export interface TokenDrift {
  readonly file: string;
  readonly token: string;
  readonly expected: string;
  readonly actual: string;
}

/** Pure: same input → byte-identical output. Throws an Error naming the token on invalid input. */
export function buildTokenFiles(designMarkdown: string): Promise<TokenFiles>;

/** Reads DESIGN.md and both generated files from the repository root; [] means no drift. */
export function findTokenDrift(): Promise<readonly TokenDrift[]>;
```

`Promise` because Prettier 3's `format()` is async.

## Generated-file header

- `_tokens.scss` starts with
  `// GENERATED by scripts/design-tokens.mjs from DESIGN.md — do not edit. Run npm run tokens:build.`
- `design-tokens.json` starts with a `"$comment"` key carrying the same text.

## Consumers

- `src/styles.scss` `@use`s `styles/tokens` and then `styles/theme`. Components read only
  `var(--kva-*)` and never the JSON.
- `design-tokens.json` is for tests and tooling only. It MUST NOT be imported by
  application code (it would enter the bundle).
